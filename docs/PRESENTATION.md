# Présentation — OPTICAL Eyewear

1. Accueil : identité turquoise et orange, logo original, univers Optique / Solaire / Lentilles, marques présentes en boutique.
2. Optique : galerie à plusieurs angles, favoris et configuration de verres avec ordonnance fictive.
3. Panier : quantités, code de test DEMO10, parcours invité, retrait à Ermont ou livraison simulée.
4. Paiement : tester le refus puis la réussite, sans carte bancaire. Consulter la confirmation dans Mon espace.
5. Boutiques : rechercher Ermont ou Gennevilliers ; montrer les vraies adresses et la carte indicative.
6. Rendez-vous : choisir boutique, motif, jour et heure ; confirmer puis annuler la réservation fictive.
7. Lentilles : choisir une boutique, renseigner un commentaire fictif et ajouter l’ordonnance de test ; confirmer localement.
8. Audioprothèse, Contact, Promotions et Avis clients : contenus adaptés au site de l’employeur, formulaires fonctionnels sans envoi.

Les prix et stocks sont simulés. Le catalogue reste illustratif faute de catalogue produit complet exploitable sur la référence. Les crédits détaillent les licences des photos et distinguent le logo client.
